## 技术栈

| 层面 | 技术选型 |
|---|---|
| 前端框架 | React 19 + TypeScript |
| 构建工具 | Vite 8 |
| 桌面框架 | Electron 42 |
| 样式 | Tailwind CSS 4 + 语义化 Token |
| 路由 | React Router 7 |
| 测试 | Vitest + Playwright |
| 代码质量 | ESLint + Prettier |

## 插件子系统

插件子系统包含四个核心模块：

- **Market**：插件市场，从远程 API 拉取插件列表，支持缓存
- **Installer**：插件安装器，处理 `.zpx` / `.zip` 格式的下载和安装
- **Registry**：插件注册表，管理已安装插件的增删改查
- **Runner**：插件运行器，以独立窗口启动插件
