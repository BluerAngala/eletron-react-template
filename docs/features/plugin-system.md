# 插件系统

集成 ZTools 插件市场，支持在线下载、本地导入、分类浏览和一键安装。

## 插件市场

插件市场页面展示在线插件列表，支持：

- **分类浏览**：按插件分类筛选
- **搜索**：按关键词搜索插件
- **安装**：一键下载并安装插件
- **详情查看**：弹窗展示插件详情和 README
- **缓存**：5 分钟缓存，减少重复请求

## 我的插件

管理已安装的插件：

- **启动/停止**：以独立窗口运行插件
- **卸载**：删除插件文件
- **导入**：从本地 `.zpx` / `.zip` 文件导入插件

## 插件格式

插件可以是两种格式：

- **ZPX**：ZTools 插件包（ASAR 格式），支持版本管理和签名
- **ZIP**：普通 ZIP 压缩包，包含 `plugin.json` 配置文件

## 插件配置

每个插件根目录必须包含 `plugin.json`：

```json
{
  "name": "my-plugin",
  "title": "我的插件",
  "version": "1.0.0",
  "description": "插件描述",
  "author": "作者",
  "main": "index.html",
  "logo": "logo.png",
  "features": [
    {
      "code": "feature-code",
      "explain": "功能说明",
      "cmds": ["命令1", "命令2"]
    }
  ]
}
```

## 插件窗口

插件以独立 BrowserWindow 运行，背景色固定为白色，不受宿主应用主题影响。
