# 国际化

## 文件结构

```
src/i18n/
  index.ts          → 导出 Language 类型、translations、LANGUAGES
  locales/
    zh-CN.ts        → 中文翻译
    en-US.ts        → 英文翻译
```

## 使用方式

```tsx
import { useLanguage } from '@/contexts/LanguageContext'

const { t } = useLanguage()
t('home.hero.title')
```

## 新增翻译键

必须同时添加到 `zh-CN.ts` 和 `en-US.ts`：

```ts
// zh-CN.ts
'home.new.key': '中文文案',

// en-US.ts
'home.new.key': 'English text',
```
