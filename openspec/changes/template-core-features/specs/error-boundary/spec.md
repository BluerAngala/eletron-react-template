## Overview

全局错误边界组件，捕获 React 渲染错误，防止白屏崩溃。

## Requirements

### 功能需求

1. **错误捕获**
   - 捕获子组件的渲染错误
   - 捕获生命周期错误
   - 不捕获事件处理器中的错误（需单独 try-catch）

2. **错误展示**
   - 友好的错误页面（不显示技术细节给用户）
   - 显示错误摘要
   - "重新加载"按钮（刷新页面）
   - "复制错误信息"按钮（方便反馈）

3. **错误上报**
   - 控制台输出完整错误栈
   - 可选：后续集成 Sentry 等错误监控

### 技术需求

- React `componentDidCatch` + `getDerivedStateFromError`
- 组件：`ErrorBoundary`
- 包裹在路由最外层

## Acceptance Criteria

- [ ] 渲染错误时不白屏，显示友好错误页
- [ ] "重新加载"按钮可刷新页面
- [ ] "复制错误信息"按钮可复制错误栈
- [ ] 控制台有完整错误日志
- [ ] 事件处理器中的错误不受影响（正常冒泡）
