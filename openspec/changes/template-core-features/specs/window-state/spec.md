## Overview

窗口状态持久化功能，记住窗口大小、位置和最大化状态，下次启动自动恢复。

## Requirements

### 功能需求

1. **保存窗口状态**
   - 窗口关闭时保存：x, y, width, height, isMaximized
   - 使用 `electron-store` 持久化到本地文件

2. **恢复窗口状态**
   - 应用启动时读取保存的状态
   - 如果有保存的状态，使用保存的尺寸和位置
   - 如果没有（首次启动），使用默认值（1200x800，居中）

3. **边界保护**
   - 如果保存的位置超出当前屏幕范围，重置为居中
   - 最小尺寸限制：800x600

### 技术需求

- `electron-store` 作为依赖
- 窗口状态存储 key：`window-state`
- 在 `electron/main/index.ts` 中实现

## Acceptance Criteria

- [ ] 关闭窗口后重新打开，窗口位置和大小恢复
- [ ] 最大化状态正确保存和恢复
- [ ] 首次启动使用默认居中位置
- [ ] 窗口最小尺寸 800x600
