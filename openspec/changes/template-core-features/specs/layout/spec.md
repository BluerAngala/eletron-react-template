## Overview

全局布局组件框架，提供侧边栏 + 顶栏 + 内容区的标准桌面应用布局。

## Requirements

### 功能需求

1. **布局结构**
   - 侧边栏（左侧）：Logo + 导航菜单 + 折叠按钮
   - 顶栏（顶部）：页面标题 + 主题切换 + 窗口控制按钮
   - 内容区（右侧）：`<Outlet />` 渲染子路由

2. **侧边栏**
   - 默认展开宽度：240px
   - 折叠后宽度：64px（只显示图标）
   - 折叠/展开动画（transition）
   - 折叠状态持久化到 `localStorage`

3. **顶栏**
   - 显示当前页面标题
   - 主题切换按钮
   - macOS 红绿灯区域适配（`-webkit-app-region: drag`）

4. **响应式**
   - 移动端（<768px）：侧边栏默认隐藏，汉堡菜单切换
   - 桌面端：侧边栏常驻

### 技术需求

- 组件：`AppLayout`、`Sidebar`、`TopBar`
- 使用 TailwindCSS grid/flex 布局
- 路由嵌套：`<Layout>` 包裹 `<Outlet />`

## Acceptance Criteria

- [ ] 侧边栏可折叠/展开，动画流畅
- [ ] 折叠状态持久化
- [ ] 顶栏显示当前页面标题
- [ ] macOS 红绿灯区域不被遮挡
- [ ] 移动端侧边栏可汉堡菜单切换
- [ ] 内容区正确渲染子路由
